# Worm parameter catalog (2026-11-06 20:29 CST)

Generated by `scripts/worm/build_ledger.py` (one command; do not edit by hand). One row per unknown: every number the model's code reads (brain, lumped layers, registry mechanisms, the body) and every number a PLAN row's published model needs that no code reads yet (**slots**, `used_by_code = slot only`). Rows are in `data/worm/model/catalog.csv`; the browser page is `viewer/worm/catalog.html` (served by `viewer/worm/serve.py`, port 8781). Counts of **numbers** count elements (a per-cell row over 302 neurons is 302 numbers); counts of **rows** count catalog rows.

Labels: **measured** (read off a cited primary source), **published_fit** (a value another project fitted or chose and published: BAAIWorm, c302, MetaWorm), **derived** (arithmetic on measured values, shown), **inferred** (reasoned from a source, ours), **guessed** (bounded placeholder, not from data), **absent** (the real worm has it; no value yet).
