Generated by `scripts/worm/build_ledger.py` (one command; do not edit by hand). One row per unknown: every number the model's code reads (brain, lumped layers, registry mechanisms, the body) and every number a PLAN row's published model needs that no code reads yet (**slots**, `used_by_code = slot only`). Rows are in `data/worm/model/catalog.csv`; the browser page is `viewer/worm/catalog.html` (served by `viewer/worm/serve.py`, port 8781).
