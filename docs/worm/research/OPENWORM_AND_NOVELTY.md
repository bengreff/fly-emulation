# OpenWorm and novelty: what has actually been fitted, and what of ours is new

Scope: does OpenWorm (and the wider *C. elegans* modelling field) already do what we propose. Four proposals checked: (1) an expression-to-physiology map from CeNGEN to channel densities, one shared function fitted on recorded neurons and tested on held-out ones; (2) homeostatic self-tuning (activity-dependent rules set densities from target activity, O'Leary/Marder style); (3) joint whole-animal fitting against whole-brain data (Randi 2023, Atanas 2023); (4) identifiability analysis before fitting. "Confirmed" = read from the primary paper/repo. "Claimed" = search-engine summary or secondary source only, primary text was paywalled, rate-limited, or not located.

## 1. What OpenWorm and the field have actually done to fit neuron parameters

### 1.1 OpenWorm core: c302, NeuroTune/PyElectro, ChannelWorm

[c302](https://royalsocietypublishing.org/rstb/article/373/1758/20170379/42135/c302-a-multiscale-framework-for-modelling-the) generates NeuroML2 models at four abstraction levels (A: integrate-and-fire, up to C/D: multicompartment conductance-based), from the Varshney/Cook connectome. It ships with two fitting tools built for it: [NeuroTune](https://github.com/NeuralEnsemble/neurotune), a generic optimiser (evolutionary algorithms, via `pyevolve`/`inspyred`) that minimises distance between simulated and target electrophysiological features; and [PyElectro](https://github.com/NeuralEnsemble/pyelectro), which extracts those features (spike width, AHP depth, etc.) from traces (confirmed, package READMEs and the [NeuroML docs](https://docs.neuroml.org/Userdocs/OptimisingNeuroMLModels.html)). These are generic infrastructure, feature-based evolutionary fitting of single-neuron or small-circuit models to electrophysiology, not specific to CeNGEN expression or to a whole animal. [ChannelWorm](https://github.com/openworm/ChannelWorm) is the matching ion-channel side: curated voltage/current-clamp traces from the literature, fit to channel kinetic models, exported to NeuroML for c302 to use. As of its own issue tracker and OpenWorm's 2024 newsletter, this remains a small, manually curated set of channels, not a CeNGEN-wide map (confirmed: GitHub [issue #40](https://github.com/openworm/ChannelWorm/issues/40); [OpenWorm Newsletter 3, May 2024](https://docs.openworm.org/fullhistory/) reports "new cell and ion channel models... developed in NeuroML" as incremental, not systematic, additions). c302's own cells at the levels OpenWorm actually runs are leaky-integrator or simplified conductance models, not per-gene channel sets (confirmed, matches this project's own `PLAN.md` table). No published OpenWorm-core work fits a channel density as a function of expression; selection is by hand, from whichever literature trace exists for that channel.

### 1.2 Sibernetic / Geppetto

Not neuron-parameter fitting. Sibernetic is a smoothed-particle-hydrodynamics body simulator (muscle model from [Boyle, Berri & Cohen 2012](https://www.frontiersin.org/articles/10.3389/fncom.2012.00010/full)); Geppetto is the visualisation/web layer. Neither fits ion-channel or expression parameters (confirmed from architecture docs; consistent with this project's `STATE_OF_THE_ART.md`).

### 1.3 BAAIWorm / MetaWorm (BAAI, *Nat. Comput. Sci.* 4(12), Dec 2024)

Two companion papers: the ["eworm" 136-neuron core-brain model](https://www.biorxiv.org/content/10.1101/2024.02.22.581686v2.full) and the full brain-body-environment integration, ["An integrative data-driven model simulating *C. elegans* brain, body and environment interactions"](https://www.nature.com/articles/s43588-024-00738-w). Method (confirmed via search-indexed abstract text and this project's local cache, not the paywalled Nature full text): cells are NEURON multicompartment models built from realistic morphology; 14 known ion-channel classes per neuron, with **passive parameters and channel conductance densities tuned by an optimisation algorithm (reported as "genetic algorithm" in secondary summaries, not confirmed from primary text) to reproduce electrophysiological traces** from patch-clamp experiments at the single-neuron level. Channel *selection* per neuron class draws on gene-expression profile (CeNGEN) plus homology to characterised channels, the same presence/absence logic as Nicoletti 2024 (below), not a quantitative expression-to-density regression. At the network level, they then trained the 136-neuron model so its activity **correlation matrix matched an experimentally measured whole-brain correlation matrix** from an earlier calcium-imaging dataset (identity of that source dataset not confirmed from primary text), reportedly reaching **mean-squared error 0.076** on that matrix (claimed, two independent secondary summaries agree; a separately reported "92.4% fidelity" figure could not be traced to a primary statistic and may be a conflation with an unrelated Randi 2023 number, unconfirmed). This is the closest OpenWorm-adjacent thing to "fit a network against whole-brain data," but it is a static correlation-matrix match, not a dynamic/causal fit, with no held-out-neuron test or identifiability analysis reported anywhere. **Achieved:** closed-loop brain+body+environment simulation reproducing zigzag chemotaxis-like trajectories qualitatively. **Not done:** CeNGEN-wide expression-to-density regression; homeostatic tuning; held-out validation; identifiability analysis.

### 1.4 modWorm (Kim, Florman, Santos, Alkema & Shlizerman; bioRxiv, posted 2025-06-12) and EP-GAN

[modWorm](https://github.com/hossein-omidi/modWorm) ([preprint](https://www.biorxiv.org/content/10.1101/724328v3)) is a 7-module pipeline (intracellular → electrical/chemical extracellular → neural activity → muscle calcium → force → posture → proprioceptive feedback) over the full 279-neuron mapped connectome (confirmed). Its own description of parameter fitting: conductance-type and synaptic-strength parameters are tuned "with respect to a given locomotion task," and the authors explicitly flag that machine-learning / deep-learning methods can be used to fit parameters (confirmed, modWorm GitHub and abstract). The directly relevant ML-fitting result from the same lab is **[ElectroPhysiomeGAN (EP-GAN)](https://elifesciences.org/articles/95607)**, Shlizerman group, *eLife* 2025, this is almost certainly the "used machine learning models to fit the neuron parameters" the project owner has in mind. Confirmed from the paper itself: EP-GAN is a GAN+RNN-encoder that maps a neuron's recorded membrane-potential/current traces directly to ~13+ Hodgkin-Huxley parameters per neuron, instantly instead of via hours of differential-evolution search (RMSE 6.7 mV vs 11.2 mV for an NSGA-II baseline on experimental data; 5 ms vs 18 hours for a 3-neuron inference task). It was applied to **9 experimental *C. elegans* neurons** (RIM, AFD, AIY, plus 6 newly recorded: AWB, AWC, URX, RIS, DVC, HSN) and validated on 200 simulated test neurons before that. The authors' own stated limits: it is "currently limited to non-spiking neurons," and it "does not necessarily recover the ground truth parameters" because multiple parameter regimes can fit the same trace, i.e. it is fast point-estimation, not identifiability-aware, and it fits **one neuron at a time from its own trace**, not a cross-neuron expression-to-parameter map, and it was never used to assemble or fit a whole connectome-scale model. **Bottom line for both:** fast, genuinely ML-based per-neuron parameter generation exists and works; neither modWorm nor EP-GAN turns that into a validated whole-animal behavioural match, and EP-GAN's own paper names the identifiability problem it leaves open.

### 1.5 Differentiable / Jaxley-based worm work

[Jaxley](https://www.biorxiv.org/content/10.1101/2024.08.21.608979) (Deistler lab, *Nat. Methods* 2025) is a general differentiable-simulation toolbox (gradient-based fitting of biophysical neuron/network models via JAX). Its own paper's demonstrated applications are rat CA1 pyramidal cells, mouse visual-cortex L5 neurons, mouse retinal ganglion cells, an RNN working-memory task, and an MNIST-classifying biophysical network (confirmed, read primary preprint text directly); **it contains no *C. elegans* application**; a widely-repeated search-engine claim that Jaxley itself trained "a 136-neuron *C. elegans* model against a whole-brain correlation matrix" is a conflation with the unrelated BAAIWorm NEURON-based result above and should be disregarded. The actual Jaxley-based worm attempt is [r-elegans](https://github.com/nih-niddk-mbs/r-elegans) (NIH/NIDDK), an unpublished, actively developed repo: differentiable, connectome-constrained (Cook 2019, 302 neurons, 3,709 chemical synapses, 1,093 gap junctions), electrophysiology seeded from Nicoletti et al., fitting via backprop-through-physics plus RL (PPO/A2C) for motor curricula. Confirmed current state (its own README): "one autonomous held bend" and "one externally paced traveling-bend fit", early curriculum milestones, not validated whole-worm behaviour. This project is itself now building on Jaxley for the worm (`PLAN.md`), so no one (including us, yet) has a published Jaxley-based whole-worm fit.

### 1.6 DevoWorm, OpenWorm.ai, and ML models that are not worm-brain surrogates

[DevoWorm](https://www.biorxiv.org/content/10.1101/282004v1.full) focuses on embryogenesis/cell-lineage modelling, not adult electrophysiology; its 2023-2026 public activity (Hugging Face org, last updated June 2025) shows no new parameter-fitting or expression-to-physiology work (confirmed, page contents). **"OpenWorm.ai"**: search summaries and a Grokipedia (AI-generated, tertiary) page describe a June 2025 announcement of a "*C. elegans*-specific large language model for model validation": an LLM documentation/validation assistant, not a neural-dynamics foundation model; this could not be confirmed against any primary OpenWorm source (publications page lists nothing past 2021; the openworm.ai domain itself could not be fetched). **Treat as claimed, likely misleadingly named, not a fitting method of any kind.** Two non-mechanistic ML efforts worth distinguishing from a real worm surrogate: **[Elegans-AI](https://www.sciencedirect.com/science/article/pii/S0925231224003692)** (Bardozzo et al. 2024) borrows the *connectome's topology* as an architecture prior for ordinary deep nets benchmarked on CIFAR/MNIST, not a model of the worm's own dynamics. **[CAPT](https://arxiv.org/abs/2607.23258)** (2026) is a cross-species calcium-imaging foundation model (mouse-pretrained, transferred to zebrafish and *C. elegans* via NeuroPAL identity) forecasting population activity, the closest thing to a worm-brain foundation model found, but statistical over calcium traces, with no channels, genes, or mechanism.

### 1.7 Bottom line on OpenWorm's fitting

Across the whole ecosystem: single-neuron/small-circuit fitting is real and uses real optimisation (evolutionary search via NeuroTune, differential evolution/NSGA-II baselines, now EP-GAN's GAN). Network-level fitting against real whole-brain data has been attempted exactly once found (BAAIWorm's correlation-matrix match), with no held-out test. No project combines CeNGEN-wide expression, homeostatic tuning, held-out-neuron validation, and identifiability analysis. Independent confirmation that no functional whole-animal reproduction exists: OpenWorm's own retrospective (late 2024, cited in `STATE_OF_THE_ART.md`) and [Claire L. Evans, *WIRED*, "The Worm That No Computer Scientist Can Crack," 27 March 2025](https://www.techmeme.com/250327/p10), stating the 13-year project has "so far failed to simulate *C. elegans*," quoting researchers (including Balázs Szigeti) that full simulation may not be achievable with current methods (confirmed via indexed coverage; paywalled at WIRED directly).

## 2. The four proposals against prior art

### 2.1 Expression-to-physiology map (CeNGEN → channel densities, one shared function, held-out test)

**Not done for *C. elegans*.** Every worm effort found (ChannelWorm, Nicoletti 2024, BAAIWorm/MetaWorm) uses CeNGEN only to decide channel *presence* per neuron class (a categorical/homology step), then fits densities per neuron or per class independently, not as one continuous function of expression level, and never cross-validated on neuron classes withheld from fitting.

**Done, closely, in mouse cortex.** [Bernaerts, Deistler, Gonçalves, Macke, Berens et al., "Combined statistical-biophysical modeling links ion channel genes to physiology of cortical neuron types," *Patterns* 2025](https://www.cell.com/patterns/fulltext/S2666-3899(25)00171-0) (preprint: [bioRxiv 2023.03.02.530774](https://www.biorxiv.org/content/10.1101/2023.03.02.530774)) is the nearest direct precedent, confirmed from its companion open-access methods paper on PMC. They (1) fit a 13-parameter Hodgkin-Huxley model per cell by simulation-based inference (neural posterior estimation, extended to "NPE-N" with injected noise to fix a failure mode) against 23 electrophysiological features, on 955 mouse motor-cortex Patch-seq neurons with matched transcriptomes; (2) built the expression → HH-parameter map two ways, linear sparse reduced-rank regression and a nonlinear sparse bottleneck network; (3) **did test generalisation across neuron types** (not a strict held-out-neuron split, but cross-cell-type prediction): "predictions were accurate at the family level but weaker at the cell-type level." Their own framing of the advance: prior work "only correlated gene expression with electrophysiology," whereas theirs routes through a mechanistic model first. This is structurally almost exactly our proposal 1, same idea, same honesty about resolution limits, but for mouse cortex, not *C. elegans*, and not tested on strictly held-out cells never seen by either the HH-fit or the regression step. The closest *Allen Institute* Patch-seq work in the same vein: [Gouwens et al. 2020, *eLife*](https://elifesciences.org/articles/65482) (coupled electrophysiology/morphology/transcriptomics at scale) and the [coupled-autoencoder cross-modal work](https://github.com/AllenInstitute/coupledAE-patchseq), both link modalities statistically; neither builds a biophysical model as the intermediate step.

### 2.2 Homeostatic self-tuning (activity-dependent rules set densities from target activity)

**Not done for *C. elegans*** as a model-building/fitting mechanism. (Separately, *C. elegans* itself biologically does this: [presynaptic CaV2/UNC-2 channel abundance self-tunes with release activity](https://pmc.ncbi.nlm.nih.gov/articles/PMC11363341/), *PNAS* 2024: real biological evidence the mechanism exists in this animal, not a model that uses it.)

**The method exists, built and validated on a tiny invertebrate circuit, not the worm.** [O'Leary, Williams, Caplan & Marder, "Correlations in ion channel expression emerge from homeostatic tuning rules," *PNAS* 2013](https://neurostatslab.org/assets/papers/OLeary_etal_2013.pdf) and [O'Leary, Williams, Franci & Marder, "Cell types, network homeostasis, and pathological compensation from a biologically plausible ion channel expression model," *Neuron* 2014](https://www.pnas.org/doi/10.1073/pnas.1516400112) (related PNAS companion) give neurons a calcium-sensing feedback rule: if time-averaged intracellular calcium is below a target, conductances are turned up (and down if above), which reproduces observed correlations between channel genes. This is run on model neurons/small networks built to resemble the crab/lobster stomatogastric ganglion (a handful of cell types), not fit against any real recorded population, and not applied to *C. elegans*. [Gorur-Shandilya et al., *Sci. Rep.* 2020](https://www.nature.com/articles/s41598-020-72977-6) and a [2025 follow-up adding voltage-dependence regulation](https://elifesciences.org/reviewed-preprints/105842v2) extend the same calcium-sensor idea (still STG-style single neurons/small models, still not whole-network real data, still not *C. elegans*). So the mechanism (O'Leary/Marder-style target-activity feedback) is established prior art in principle; applying it as a fitting/regularisation method for a real 302-neuron connectome constrained by real recordings is not found anywhere.

### 2.3 Joint whole-animal fitting against whole-brain data (Randi 2023, Atanas 2023)

**Both datasets exist and have been used for fitting, but only within much simpler model classes, and not jointly.** [Randi, Sharma, Dvali & Leifer, "Neural signal propagation atlas of *C. elegans*," *Nature* 2023](https://www.nature.com/articles/s41586-023-06683-4): the atlas was built *by* fitting a connectome-constrained dynamical model (a linear/low-order causal-propagation model, not channel-level) to 23,433 optogenetically-perturbed neuron pairs' whole-brain calcium responses, capturing causal interactions 92% as well as the data's own reproducibility (confirmed). A 2025 follow-up, [Creamer et al., "Bridging the gap between the connectome and whole-brain activity in *C. elegans*"](https://pmc.ncbi.nlm.nih.gov/articles/PMC12485687/), extends this with multi-hop propagation and explicitly reports **held-out-neuron prediction** (confirmed from abstract/PMC text), the one place found where a worm whole-brain model is checked against neurons withheld from fitting, though still an abstract dynamical system, not channels or genes. [Atanas, Kim et al., "Brain-wide representations of behavior spanning multiple timescales and states in *C. elegans*," *Cell* 2023](https://www.biorxiv.org/content/10.1101/2022.11.11.516186.full.pdf) (the freely-moving whole-brain dataset) was used to fit **CePNEM**, a per-neuron probabilistic encoding model (confirmed); again statistical/phenomenological, one neuron at a time, not a shared mechanistic model. [Morrison & Young, "A data-driven biophysical network model reproduces *C. elegans* premotor neural dynamics" (arXiv 2501.00278, 2025)](https://arxiv.org/abs/2501.00278) is the closest approach to ours found: a biophysical (not just statistical) model of the premotor circuit, fit using whole-brain imaging data to constrain parameters, reproducing higher-order activity statistics (forward/reversal switching, subnetwork synchrony), but scoped to the premotor sub-circuit (order-10 neurons with feedforward sensory/interneuron drive), not the whole animal, and not jointly fit against both the Randi perturbation atlas and the Atanas freely-moving dataset together. **No project found fits one full-animal, channel/gene-level mechanistic model jointly against both Randi 2023 and Atanas 2023**; each dataset has driven its own, narrower model class.

### 2.4 Identifiability analysis before fitting

**Not done, as a pre-registered step, for any whole *C. elegans* nervous-system model.** The general statistical machinery is decades old and well outside the worm field: [Gutenkunst et al., "Universally Sloppy Parameter Sensitivities in Systems Biology Models," *PLoS Comp. Biol.* 2007](https://journals.plos.org/ploscompbiol/article?id=10.1371%2Fjournal.pcbi.0030189) established that large biological ODE/kinetic models generically have a few data-constrained ("stiff") parameter combinations and many unconstrained ("sloppy") ones; directly the problem our proposal 4 is guarding against, and this has been refined since (profile likelihood, structural vs. practical identifiability; see e.g. the 2025 review ["Think before you fit"](https://arxiv.org/html/2508.18853v1)). Applied to single *C. elegans* neuron models, [Nicoletti et al. 2024](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0298105) and its predecessor [Nicoletti et al. 2021 (AWCon/RMD)](https://journals.plos.org/plosone/article?id=10.1371%2Fjournal.pone.0218738) discuss sensitivity of fitted conductances informally but do not run a systematic identifiability analysis before fitting, and no whole-network *C. elegans* paper found (BAAIWorm, modWorm, Randi, Atanas, Morrison & Young) reports one either. This project's own `docs/worm/research/NEUROPEPTIDES.md` already flags the same gap for the neuropeptide layer specifically (1,844 possible ligand-receptor parameters vs. ~300 the data can support), consistent with, not contradicting, this finding: nobody in the literature has made identifiability analysis a gate before fitting a worm-scale model.

## 3. Verdict table

| Proposal | Prior art | How ours differs | Risk |
|---|---|---|---|
| 1. Expression → physiology map (CeNGEN, shared function, held-out neurons) | Mouse cortex: Bernaerts/Deistler/Berens/Macke, *Patterns* 2025, SBI-fit HH params + sRRR/NN map from Patch-seq expression, cross-cell-type tested, weaker at fine cell-type level. Worm: only categorical presence/absence via homology (ChannelWorm, Nicoletti 2024, BAAIWorm) | Same structural idea, applied to CeNGEN with actual held-out *recorded* neurons (not just held-out cell families); worm has single-cell transcriptomes for the *whole* nervous system (118 classes), which mouse cortex Patch-seq does not | Mouse result shows the map degrades below the family level; worm version may hit the same ceiling with less data to fall back on (fewer recorded neurons overall) |
| 2. Homeostatic self-tuning (target-activity feedback sets densities) | O'Leary/Marder 2013-2014, Gorur-Shandilya 2020/2025: same feedback rule, STG-style model neurons/small networks, no real-recording fit, not *C. elegans*. Biologically, *C. elegans* does self-tune (CaV2/UNC-2, 2024) | First use of the rule as a fitting/regularisation mechanism against a real 302-neuron connectome and real recordings, not a hand-built small model | The rule's correlations were derived to match *qualitative* STG channel co-expression; whether it helps or fights a quantitative CeNGEN-constrained fit is untested either way |
| 3. Joint whole-animal fit against Randi 2023 + Atanas 2023 | Randi's own atlas-fit: connectome-constrained linear/causal model, not channel-level. Creamer 2025: extends this, with held-out-neuron prediction: the strongest existing precedent. Atanas: CePNEM, per-neuron statistical. Morrison & Young 2025: biophysical but premotor-circuit-only, single dataset | Full-animal, channel/gene-level mechanistic model, fit jointly against *both* datasets at once, rather than one dataset driving one narrow model class | Nobody has shown a channel-level model can even approach Randi/Creamer's causal-interaction fit quality; joint fitting multiplies compute and failure modes before any single-dataset result is in hand |
| 4. Identifiability analysis before fitting | General method 20+ years old (Gutenkunst 2007 and descendants); never applied as a pre-registered gate to a whole *C. elegans* model; this project's own `NEUROPEPTIDES.md` already does it informally for one layer | Applying it systematically, before fitting, across the whole parameter set (channels + peptides + gap junctions), as a standing step rather than a post-hoc check | Real but well-understood methodological risk: a sloppy-but-well-predicting model (per Gutenkunst/Sethna) could pass identifiability concerns and still be the right thing to ship; analysis must inform, not block, fitting |
