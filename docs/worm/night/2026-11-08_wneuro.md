## Item 5, homeostasis set point

`scripts/worm/wneuro/homeo_setpoint.py` (bar written 23:16, before running). The template brain is near its basal
Ca in the set window and after it: c0 median 0.0506 uM, later mean 0.0503 uM (measured); the start-up transient is
under 1% (median 0-0.5 s vs 1.5-2 s -0.8%, measured). So the 2 s window does not catch a transient, and the rule
is not class A. The one-sidedness is real but comes from two things that are not code defects:
(i) the published rule's own bound, err = (c0 - Ca) / c0 <= 1 because Ca >= 0 (O'Leary et al. 2014), and
(ii) the open-loop brain's resting state: most neurons sit at the basal Ca floor during the set window, so later
activity can only push err negative, and densities can only fall. The cited C. elegans measurement is in that
direction (PMC11363341: UNC-2 falls after more than 2 h of stimulation); up-regulation after silencing is not
cited in the module and not looked for tonight. Re-check after wbrain2's bulk Ca pool merges (it changes the Ca the
rule reads).
Session 3: closed without a run, because the premise was wrong. The rule reads ctx.ca, the soma's cai (brain.py:392
pointer, :893), and the bulk pool (mech/capool `ca_bulk`, nmodl/cabulk.mod) "reads the soma's total ica and writes
neither cai nor ica"; only the GCaMP readout reads `ca_bulk_uM` (mech/observation.py:192). So the set point is the same
with ca_bulk on or off. A re-run would be needed only if the rule were moved to read bulk Ca, which would be a new
choice of sensor needing its own source.

point source (Sykova and Nicholson 2008, Eq 13 at t to infinity); the HSN route now goes through the same
`_field_nM` and reproduces its stored value exactly (9.238974470524608 nM, measured). Per-route geometry comes from
Cook et al. 2019's chemical counts as the brain holds them (`st.chem`): a pre cell p with n_p synapses onto the post
cell has n_p release sites in a row, `syn_site_spacing_um` apart; each site releases `syn_release_share` x J_p /
N_out(p), N_out(p) being p's total Cook output count, so a cell's release is shared over all its synapses; the receptor
sits `syn_site_receptor_um` from the middle site; the read is the largest pre-cell cluster (not a sum: no source puts
two cells' synapses in one place). Three new Specs, labelled in the code:
- `syn_site_receptor_um` 0.1 um (0.02-1), guessed, the same unknown as `hsn_vm2_site_receptor_um`.
- `syn_site_spacing_um` 0.625 um (0.5-20), inferred from Patel et al. 2006's 16 HSN sites over 10 um (10 / 16,
  derived); the upper bound is guessed.
- `syn_release_share` 1.0 (0.1-1), guessed: the fraction of a cell's release made at its synapses.
Metabotropic receptors only. MOD-1, LGC-55 and LGC-53 at synapses are already the brain's synapse layer
(receptors.py, cleft `rec_tmax_<amine>_uM`), so a near-field read for them would count the synapse twice. Neutral by
default: `amine_synaptic=off` returns 0 on every route (test). `test_amine_synaptic_routes`: HSNL's Cook output 125;
the closed form at alpha 1, tortuosity 1, h 1, share 0.5; off gives 0; no synapse gives 0; the largest cluster wins;
linear in J.
