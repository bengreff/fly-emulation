- Fix: `expression_map=on` no longer masks a density whose ledger label is published_fit or measured. Every BAAIWorm
  density is a published fit (5 co-tuned sets fitted to AIYL, RIML, AVAL, AWAL current clamp and AWCL, VD05 voltage
  clamp, then assigned to the other cells by BAAIWorm), so the mask now acts on none of them; the Nicoletti channels'
  CeNGEN-based densities (mech/channels, guessed or inferred per class) are unchanged. The old form is `cengen_all`.
- Checks and bars:

    triage's mask-off count, 7 Nov). The -150 mV floor is reported; the triage expects it to rise (92 with the mask

### Line 3, the NMJ GABA IPSC (20:34)
- Fix: `rec_gabacl_tau_off_ms` was the evoked IPSC's decay (24.8 ms, a composite of release and receptor closing) used
  as the receptor's own closing time. It is now derived: the receptor tau solved so that the model's evoked IPSC
  (BAAIWorm's release state, 1/k = 8.6 ms after a 2 ms step, then the receptor) decays in 24.8 ms. Derived 19.16 ms,
  bounds 15.45 and 22.69 ms (the composite at 22.1 and 27.5 ms). `scripts/worm/debug2/derive_gaba_tau_off.py`.
- Check and bar: `at_ledger.py receptor_unit_check.py`, composite NMJ IPSC decay inside 22.1-27.5 ms (Liu, Hollopeter
  and Jorgensen 2009, 24.8 +- 2.7 ms, n = 12); the UNC-49 step decay must stay inside 134-164 ms.

### Line 7, the AWA Kir (20:41)
- Fix: new toggle `awa_kir`, default `smooth_min`: I_Kir = I0 - beta log(1 + exp(-(gKir (v - vK) - I0)/beta)), the
  smooth minimum of the ohmic K current and Table S4's saturated current I0 = 5.0 pA (beta 5.0 read as pA). Form
  `as_printed` is the old equation, kept for attribution. Mod `kir_form`, I0d, betad; CPU reference
  `senses_checks.liu_kir`. Chosen over the mV reading (I0 added to v) because Table S4 defines I0 as a current
