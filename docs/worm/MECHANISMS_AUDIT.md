**Categories (strict, unchanged from 5 Nov):**

- **full**: runs in the model at the level PLAN.md asks, as a published mechanistic model. Parameter quality is
  separate (the catalog's labels answer it). Where no published model exists (docs/worm/research/PORT_SOURCES),
  a row is at most lumped.
- **lumped**: real dynamics that act on a run, but simpler than PLAN.md asks: fewer states, one value shared where
  the plan wants one per class, a pool in place of cells.
- **spec only**: values in the code or ledger, or a state, that nothing with dynamics reads.
- **missing**: nothing in the code.

A row is counted under its main category; parts in another category are named in the row. **Exercised** = switched
on in a test or run. **Checked** = scored against a bar written before the run.

**Every row 1-28 is on in the v1 loop** (29 is a readout of that loop; 30 is off and outside mech.REGISTRY). `scripts/worm/wbody_loop_check.py 20 v1_everything --modules=observation
--env=standard` (7 Nov 01:03, 5b7e141): 23 modules, 60 toggles on (off: bwm_coupling, muscle_active and brain_layers'
old glia gain, all superseded), the row 22 plate, the layered body on the agar film. 20 bio s, finite, 11.85 s wall
per bio s (measured; Mac load about 1-2). So "exercised" below always includes this run and is not repeated.

**Numbers** are the catalog's per-PLAN-row counts (`docs/worm/CATALOG.md`, built from `data/worm/model/
parameters.csv`: 1,206 rows, 90,950 numbers at 7b49648), split measured / published fit / derived / inferred /
